# Workflow de documentation

Ce workflow sert de référence visuelle au site statique. Les fichiers JSON du
workflow alimentent les pages de phases et `guide.json` alimente `guide.html`.
La phase `04-generation-site.json` décrit la chaîne de publication de bout en
bout : moments d'édition, actions utilisateur, outils, fichiers lus et produits,
contrôle du résultat, jugement ergonomique et améliorations proposées.

Le guide présente les capacités du modèle JSON, celles disponibles directement
dans Mermaid 11.17.2 et les limites vérifiées du rendu `swimlane-beta`. Il doit
rester utilisable sans accès à Internet : toute nouvelle image ou bibliothèque
d’icônes doit être ajoutée aux ressources locales avant d’être utilisée.
